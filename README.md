# DigitalBookshelf

A digital bookshelf and reading tracker built with HTML, CSS, and JavaScript.

## Features

- Add books manually or search for books using the Open Library API
- Different book spine designs based on genre
- Drag and drop books to organize the bookshelf
- Track reading progress
- Save books and reading progress using LocalStorage
- Responsive design for desktop, tablet, and mobile - still in progress
- Separate reading mode with ambient music

## Live Demo

[Try the Digital Bookshelf](https://leticiahalm.github.io/DigitalBookshelf/)

## About

This project was created as a web development project to practice HTML, CSS, JavaScript, API integration, LocalStorage, and responsive web design.
